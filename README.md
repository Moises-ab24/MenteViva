# 🧠 Mente Viva

Manual interactivo de salud mental, construido como sitio web.

## 📖 ¿Qué es?

Mente Viva es un manual de salud mental dirigido a jóvenes, desarrollado como
proyecto de Psicología. Se construyó como sitio web
interactivo con estilo neubrutalista, animaciones y tres actividades
prácticas.

Ya disponible en (https://menteviva.pages.dev/)

Cubre tres temas principales:

- **Manejo de emociones** — qué son las emociones, por qué reprimirlas tiene
  consecuencias reales, y estrategias con respaldo científico para
  regularlas.
- **Estrés académico** — qué lo distingue del estrés normal y técnicas
  concretas (Pomodoro, matriz de Eisenhower) para manejarlo.
- **Uso saludable de redes sociales** — qué dice la investigación sobre el
  efecto de las redes en el bienestar, y cómo pasar de un uso compulsivo a
  uno consciente.

Cada tema viene acompañado de una actividad interactiva para poner en
práctica lo leído, y todo el contenido está respaldado con fuentes
bibliográficas en formato APA 7.

## 🛠️ Stack

| Capa | Tecnología |
|---|---|
| Framework | React 19 + TypeScript |
| Build tool | Vite |
| Animaciones | Framer Motion |
| Estilos | CSS Modules (sin librerías de UI externas) |
| Persistencia | LocalStorage (diario de emociones y organizador anti-estrés) |
| Tipografía | Fraunces · Space Grotesk · JetBrains Mono (Google Fonts) |
| Deploy | Cloudflare Pages |

## ✨ Funcionalidades

- 📓 Diario de emociones interactivo, con historial guardado en localStorage
- 🗂️ Organizador anti-estrés basado en la matriz de Eisenhower (urgente / importante), también persistente
- 📊 Test de hábitos digitales con resultado calculado según las respuestas
- 🎨 Diseño neubrutalista: bloques con sombra dura, bordes marcados y paleta de colores asociados a salud mental (verde, celeste, lavanda)
- 🧭 Navegación con scroll-spy — resalta la sección activa tanto en desktop como en el menú mobile
- 📱 Totalmente responsive, con layout propio para desktop y mobile en cada sección
- 📚 Página de fuentes bibliográficas separada, en formato APA 7
- 🎬 Animaciones de scroll-reveal y transiciones entre pestañas con Framer Motion
